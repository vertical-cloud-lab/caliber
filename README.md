CALIBER: A Retrieval-Augmented, Uncertainty-Aware Platform for Selecting High-Fidelity Characterization Parameters for Novel Alloys

Understanding a novel metal alloy's properties depends on accurate characterization, but leading analytical methods (SEM, EDS, EBSD, XRF) only return representative results when their acquisition parameters are set correctly. For example, standardless SEM-EDS can over-report trace Mg in AlSi10Mg several-fold, and EBSD indexing yield on laser powder bed fusion-derived Al-Si can vary from 40% to 80% once beam current and the phase model were corrected. Finding the right parameters takes trial-and-error. We present CALIBER, an AI-enabled platform to help address this that couples characterization literature through retrieval-augmented generation (RAG), a growing experimental dataset, and an uncertainty-aware feedback loop. Based on these, the model recommends high-fidelity acquisition settings for a given sample and analysis goal. Combining established characterization knowledge with data we collect in-house yields a literature- and physics-grounded method for choosing baseline parameters. This reduces the time needed to reach compositional and microstructural analysis of new alloys.
