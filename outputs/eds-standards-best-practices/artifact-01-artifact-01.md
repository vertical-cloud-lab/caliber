| Parameter Category | Parameter | Requirement | Notes/Rationale |
|---|---|---|---|
| Must be identical | Beam energy (E0) | Exact same set point for standard and unknown | k-ratio protocol assumes identical excitation conditions; verify actual beam energy from the continuum end point/Duane-Hunt limit as a QC check, especially when reusing archived standards (pqac-00000026, pqac-00000007) |
| Must be identical | EDS detector | Same physical detector | Archived standards are detector-specific because window transmission, solid angle, and response function are part of the measured standard spectrum (pqac-00000001, pqac-00000010) |
| Must be identical | Pulse process time / time constant | Same setting | Time constant controls resolution, peak shape, and throughput; archived standards are only valid if the same processing conditions are used (pqac-00000002, pqac-00000005, pqac-00000028) |
| Must be identical | Detector-to-specimen distance / effective solid angle | Same geometry; in practice maintain the same working distance and detector position | Measured intensity scales with solid angle; even if the detector flange is fixed, working distance and specimen height must reproduce the archived-standard geometry (pqac-00000001, pqac-00000005, pqac-00000031) |
| Must be identical | Takeoff angle / detector elevation geometry | Same geometry | X-ray absorption corrections depend on emergence angle, so archived standards should only be reused under the same takeoff geometry (pqac-00000001, pqac-00000026, pqac-00000031) |
| Must be identical | Specimen tilt angle | Ideally 0° for both; if tilted, tilt must match exactly | Tilt changes path length and absorption; low-tilt, flat geometry is strongly preferred for quantitative work (pqac-00000001, pqac-00000031) |
| Must be identical | Conductive coating scheme | Same coating material and nominal thickness | Coating differences can shift analytical totals and bias k-ratios; for low-kV work (≈5 keV and below) matching coating thickness becomes especially important (pqac-00000017, pqac-00000031, pqac-00000032, pqac-00000033) |
| Must be recorded | Probe current (beam current) | Measure or otherwise normalize and record for each session | Dose = beam current × live time; absolute current is preferred via Faraday cup/picoammeter, but if unavailable a QC-standard intensity can be used to normalize dose within a verified workflow (pqac-00000002, pqac-00000006, pqac-00000007) |
| Must be recorded | Live time | Record accurately using the dead-time-corrected live-time clock | Dose normalization requires live time, not just real time; intensity should scale linearly with effective dose (pqac-00000007, pqac-00000026) |
| Must be recorded | Acquisition date/time and session metadata | Record for traceability | Needed for archived-standard provenance, long-term QC charts, and troubleshooting drift or maintenance events (pqac-00000008, pqac-00000010) |
| Must be in an acceptable range | Dead time | Keep low; about ≤10% recommended for SDD quantitative work, and more conservative for trace work | Dead time does **not** need to be identical between standard and unknown; it must simply stay in a regime where coincidence/pile-up artifacts are negligible and correction remains reliable (pqac-00000000, pqac-00000012, pqac-00000027, pqac-00000028) |
| Must be in an acceptable range | Input/output count rate | Any rate that preserves stable calibration/resolution and acceptable dead time | Modern SDD systems tolerate high throughput, but very high count rates increase coincidence artifacts; choose rates by detector behavior, not by forcing equality between standard and unknown (pqac-00000009, pqac-00000011, pqac-00000027) |
| Must be in an acceptable range | Spectrum integrated counts | Sufficient for the target precision | High-count spectra are essential for minor/trace work and robust peak fitting; examples in the literature range from millions to tens of millions of counts depending on problem difficulty (pqac-00000012, pqac-00000022, pqac-00000025) |
| Must be in an acceptable range | Surface roughness / polish quality | Better than ~100 nm RMS generally; better than ~50 nm RMS for low-energy photons (<1 keV) | Surface topography changes absorption and geometry; low-kV Al/Si/Mg K analysis is especially surface-sensitive, so final polish quality matters directly to k-ratio validity (pqac-00000001, pqac-00000031, pqac-00000032) |


*Table: This table separates conditions that must be strictly matched from those that only need documentation or control within acceptable limits when reusing archived bulk SEM-EDS standards. It is useful for building a reusable per-voltage standards library without imposing unnecessary constraints such as identical dead time.*
